Inbox

Inbound customer messages that are not classified yet, or whose classification waits for a decision. Classify asks the model (behind redaction); every result is checked by code against the message and the ledger. Accept applies the rule for the label (a dispute or promise event on the invoice); Reject discards it. Confidence is the model's own score, not a probability: it only decides what needs review.

A date without a year is read as the occurrence nearest to the day the message was sent.
